# Task 4 - Responsive Design Tokens & Mobile-First CSS Architecture

## Project Overview

This project demonstrates a responsive enterprise dashboard built using modern CSS architecture.

The project focuses on:

- CSS custom properties (design tokens)
- Mobile-first responsive design
- CSS Grid
- Flexbox
- Responsive breakpoints
- Glassmorphism
- Soft shadows
- Hover transitions
- Dark/light theme variables
- Responsive layouts without horizontal scrolling

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Custom Properties
- CSS Grid
- Flexbox

## Design Tokens

The project defines reusable design tokens inside `:root`.

The token system includes:

- Brand colors
- Background colors
- Typography sizes
- Font weights
- Spacing values
- Border radii
- Shadows
- Transitions

Example:

```css
:root {
  --color-primary: #2563eb;
  --space-md: 16px;
  --radius-md: 12px;
}
